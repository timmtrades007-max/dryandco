Launch guide

Make dry&co live + run a Pulse page

Your full site is already built locally. Follow these steps to open it on this PC, put it on the internet, and use the Pulse landing for ads.

Site folder: C:\Users\timme\Downloads\dryco-website\
Open index.html for the full brand site · pulse.html for campaigns.

1. Open it locally (now)

  1. Double-click index.html — or run a tiny local server (cleaner for testing):
cd C:\Users\timme\Downloads\dryco-website
python -m http.server 8080

Then visit http://localhost:8080 in your browser.

2. Before public launch — 3 edits

  1. WhatsApp number — in assets/js/app.js find wa.me/27600000000 and replace with Charne’s real number (country code, no + or spaces). Also update the link on pulse.html and phone/email in the footer.
  2. Domain email — swap hello@dryandco.co.za once the domain is yours (or use a Gmail temporarily).
  3. Product photos — lifestyle frames from Charne’s video are in place; add flat-lays of real stock as you produce them.

3. Put the full website live (free, ~2 minutes)

Option A — Netlify Drop (easiest)

  1. Go to app.netlify.com/drop
  2. Drag the whole dryco-website folder onto the page
  3. You get a live URL instantly (e.g. something.netlify.app)
  4. Add custom domain later: dryandco.co.za via Netlify Domain settings + your registrar (xneelo, Domains.co.za, Cloudflare, etc.)

Option B — Cloudflare Pages / Vercel / GitHub Pages — same idea: upload or connect a Git repo of this folder; set the publish directory to the site root.

Option C — SA host — upload via cPanel File Manager or FTP to public_html on xneelo, Afrihost, Hostinger, etc.

4. What is the Pulse website?

pulse.html is a single-screen campaign landing page — faster load, one message, four hero prices, WhatsApp CTA. Use it when you need a “pulse” of traffic from Instagram ads, WhatsApp Status, or broadcast lists without sending people into the full shop maze.

  • Full site: / or index.html — brand + catalogue
  • Pulse: /pulse.html — ads & chat conversions
After Netlify deploy, your Pulse link looks like:
https://YOUR-SITE.netlify.app/pulse.html
Put that URL in Meta Ads, Instagram bio during launches, and WhatsApp broadcasts.

5. Pulse marketing rhythm (recommended)

  1. Post Charne’s film + site link on Instagram / TikTok
  2. Run a small Meta ads Pulse campaign to pulse.html (Dry Robe + Blanket offer)
  3. All checkouts go WhatsApp → confirm size → Send Yoco / PayFast / EFT link
  4. Weekly “pulse”: one Story, one product, one WhatsApp broadcast

6. Domain checklist (South Africa)

  1. Register dryandco.co.za or dryandco.com
  2. Point DNS to Netlify / Cloudflare / your host
  3. Turn on HTTPS (automatic on Netlify/Cloudflare)
  4. Create Instagram @dryandco and WhatsApp Business profile with the logo end-card

7. Next upgrades (when you’re ready)

  • Yoco or PayFast payment links
  • Shopify / WooCommerce if order volume grows
  • Professional product photography of first stock batch
  • Google Business Profile for Cape pop-ups
