# dry&co — luxury dog brand website

Cape-born higher-end dog products. Full static site ready to open locally or deploy.

## Open now

```bash
cd C:\Users\timme\Downloads\dryco-website
python -m http.server 8080
```

Visit: http://localhost:8080

Or double-click `index.html`.

## Pages

| File | Purpose |
|------|---------|
| `index.html` | Full brand home |
| `shop.html` | 18 products in ZAR |
| `about.html` | Brand story + logo |
| `contact.html` | Enquiries / wholesale |
| `pulse.html` | Ad / WhatsApp landing |
| `GO-LIVE.html` | Deploy + Pulse guide |

## Before public launch

1. Replace WhatsApp number `27600000000` in `assets/js/app.js` and `pulse.html`
2. Update email / phone in footers
3. Drag folder to https://app.netlify.com/drop for instant live URL
